### Fixed: Long labels in detail lists no longer run into their value

In detail lists such as a user's *Activity* panel, a label as wide as its column ended right where
the value begins, so it read as "Two-factor authenticationOff" ([GH#738]). Long labels now wrap
inside their column and keep a gap before the value.
