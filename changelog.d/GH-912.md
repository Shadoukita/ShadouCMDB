### Security: CI tests run against a PostgreSQL image pinned by digest

The PostgreSQL service container in the test, DAST and upgrade workflows is now pinned by digest, the
same image the release workflow already uses ([#912]). A re-pushed `postgres:17` tag can no longer
change the database the tests run against.

**Upgrade:** nothing to do. This changes the project's CI only, not the shipped software.

[#912]: https://github.com/Shadoukita/ShadouCMDB/issues/912
