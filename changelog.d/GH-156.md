### Fixed: sort selects no longer list "Label" twice

In **Administration › Customization › List views** (Default sort) and **Dashboard** (a saved-search
widget's Sort by), the empty choice read "Label (built-in)" or "Label" next to the Label field itself.
It now reads **Default (label, ascending)**, which is what it applies ([GH#156]). Attribute sorts
(`attributes.<key>`, including those migration 0020 wrote on upgrade) were already shown and selectable
in both selects and on the inventory's column headers since the attribute-sort UI change. No API or
database change.
