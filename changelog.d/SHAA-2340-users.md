### Changed: Administration › Users in the new look

The Users list now has the same header as the inventory. The breadcrumb, the title with the
user count, **New user**, the introduction, and the search and filters sit on one band above the
table. Usernames are shown in a monospaced font in the link colour. Status is shown as a pill
with a dot (**Active**, **Disabled**). The page numbers sit in the footer of the table.

A user's page has the same header as a CI page. It shows the breadcrumb and a user icon on a
tile, the username in a monospaced font, and the status, administrator, MFA, identity provider and
sign-in chips. Below them are the display name and the last sign-in. The actions are unchanged.

No behaviour, URL or permission changes.
