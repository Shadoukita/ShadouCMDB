### Security: impact and service-member CSV exports neutralise every spreadsheet formula

The **Impact analysis** CSV export and the business-service **Members** CSV export used their own
formula guard, which missed values starting with spaces before `=`, `+`, `-` or `@` and the
full-width forms `＝` `＋` `－` `＠`. A spreadsheet program opening such an export could run a
formula from a CI name (CSV injection, [GH#388]). Both exports now use the same rule as the import
error report and template: every field is quoted, and a value a spreadsheet could read as a formula
is prefixed with `'` (a value already starting with `'` gets a second one). A line break inside a
CI name now stays inside its quoted field instead of being replaced with a space. No database
change; the columns and the first comment row are unchanged.

[GH#388]: https://github.com/Shadoukita/ShadouCMDB/issues/388
