### Fixed: a CI's own layout and a layout template are limited to 256 KiB

`PUT /api/v1/configuration-items/{id}/layout` and `PUT /api/v1/ui-settings` now refuse a layout
larger than 256 KiB as JSON with `400 VALIDATION_ERROR`, code `too_large`, on the field `layout`
(or `settings.layoutTemplates.<n>.layout`) ([GH#533]). Before, a CI's own layout had no limit of
its own: a large layout that compressed badly was refused by a database check, and the error named
the internal table and constraint instead of the field. The limit counts the layout as the server
stores it, so it no longer depends on how well the content compresses. The database check stays as
a backstop.

**Upgrade:** nothing to do. Layouts already stored keep working; a settings document whose template
is over the limit has to be made smaller before the settings can be saved again.

[GH#533]: https://github.com/Shadoukita/ShadouCMDB/issues/533
