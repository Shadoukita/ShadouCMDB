### Added: Owner and end-of-life fields in the class editor

**Administration › Data model › Classes** now sets the two data-quality fields of a class on its
page: **Owner field** and **End-of-life field**. They decide which CIs the dashboard's "Without an
owner" and "End of life" checks count. Each list offers only the fields the check accepts (owner:
text, choice list, lookup list or reference; end of life: date or date and time), the inherited
fields included. A class without its own setting shows the one it inherits ("Inherited from
Server: Owner"), or that the check is off for it. If the API refuses a setting, the reason is
shown next to the field.

Until now these settings could only be changed through the API. If migration `0068` did not set
them on your classes because your fields use other keys, set them here to turn the checks on.
