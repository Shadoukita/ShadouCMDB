### Changed: Administration › Starter templates in the new look

The starter templates page now has the same header as a CI page, with the number of templates and how many
of them are installed. Each template is a panel with its status (not installed, partly installed, installed)
as a pill next to its name and the install button at the end of the header. The page is available in English
and German.

No URL, permission, API or install behaviour changes.
