### Changed: Navigation, dashboard and shared screen elements take their texts from the message catalog

The header, the main menu, the user menu, the global search, the breadcrumb trail, the dashboard,
the "page not found" screen, the pagination bar, error messages and the form error summary now
take every text from the application's message catalog, which has an English and a German version.
The interface stays in English: there is no language setting yet, and the wording is unchanged.
A text that has no German version yet is shown in English, never as an internal key.
