### Changed: Import wizard in the new look

The import wizard now has the same header as a CI page. The file name is shown in a monospaced font, with
the status, the target class and the number of rows as chips, and the start time below. The steps (Upload,
Map columns, Check, Import) are joined by connectors, and finished steps show a check mark.

Stopping an import now works the same way in every phase. While a file is being read, checked or imported,
a Stop import button sits in the header and asks for confirmation first, as on the Imports page. Before
this change, reading and checking stopped without asking. Once an import has stopped, Delete import is in
the header's action menu. The wizard is available in English and German.

No URL or permission changes.
