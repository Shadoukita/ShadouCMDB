### Changed: Sidebar sections, saved views in the sidebar and the user block at its bottom

The sidebar groups its entries under **Workspace** (Dashboard, All configuration items, Bulk import,
Business services, Workflows) and **Administration** (Audit log, Administration); the former
**System** heading is now **Administration**. All configuration items shows the number of CIs the
user may view, abbreviated (for example 12.4K), with the exact figure as its tooltip. A new
**Saved views** section lists the user's inventory views and the shared views available to them;
each opens the inventory with that view applied. Views that can no longer be applied are left out.

The signed-in user moved from the header to the bottom of the sidebar, showing their name and
whether they are an administrator. It opens the same menu (My account, theme, density, Sign out);
in the collapsed sidebar it shows the initials. Below 820 px wide, where the sidebar is a drawer,
the user menu stays in the header. The header keeps the global search (press `/`) and **New CI**.
