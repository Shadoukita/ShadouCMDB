### Changed: New colour palette for the web UI, in light and dark

The web UI has a new colour palette as part of its redesign. The light theme uses warm grey surfaces with white panels and a teal primary colour; status colours are green, amber and red. The dark theme uses a deep blue-grey canvas with a lighter teal primary colour and dark button labels. The navigation sidebar stays dark in both themes, and its default highlight colour is teal. Page titles and dashboard figures are larger, and panels and buttons have rounder corners. Every text colour, control border and focus ring in both themes meets WCAG 2.1 AA (4.5:1 for text, 3:1 for control borders and focus rings), and a unit test enforces it.

Brand colours set in Customization › Branding still take precedence and are still contrast-checked. Only installations without a custom primary or accent colour see the new defaults. Theme selection is unchanged: each user's own choice, otherwise the administrator's default, which can follow the operating system's light or dark setting.
