### Changed: Administration data model pages

- **One list layout:** the **CI classes**, **Areas**, **Relationship types** and **Dropdowns** pages now look and work like the other administration lists. Each has one toolbar with the main **New** action, a short introduction and an empty state that says how to create the first entry. Row actions such as Edit and Delete are in the row's **More actions** (`⋯`) menu. A successful change is confirmed by a notification.
- **Class page:** the page starts with a title row: the class icon, the name, the area, the technical name and the last change. It saves the same way as a configuration item, with the bar at the bottom of the window. **Open inventory** and the other class actions are in the title row.
- **Attributes:** form sections in the attribute table read as group headers. You can still reorder attributes by dragging or with the arrow buttons.
- **Schema change confirmation:** the dialog that shows what a change does to the database now uses plain headings. Where a change asks you to type the name to confirm, you now type it into a normal field. The checks and the confirmation itself are unchanged.
- **German:** every data model page, dialog and message is now available in German, including the class icon names.
