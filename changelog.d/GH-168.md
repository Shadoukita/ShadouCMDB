### Fixed: adding a column to a list view that shows the default columns keeps them

A list view stored without columns shows the default columns (Label, Ident, Class, Active, Updated).
Migration 0020 writes such views for every class that had a default sort saved in v0.1.0-rc.1, and the
settings API and configuration import accept them. In **Administration › Customization › List views**,
adding, removing or moving a column on such a view started from an empty list, so saving left the
inventory with only the new column, and without the Label column that opens a CI ([GH#168]). The
editor now lists the default columns for these views and every change starts from them. Views saved
with the defaults only are unchanged. No API or database change.

[GH#168]: https://github.com/Shadoukita/ShadouCMDB/issues/168
