### Changed: Criticality in list views and detail and form layouts

*Customization → List views* now offers **Criticality** as a column and as the default sort of a
class's list, so the column no longer has to be picked in *Columns* each time.

*Customization → Detail and form layout* and the layout editor treat Criticality like the other
core fields of every CI: it can be moved to any tab and section, made read-only on the form, or
hidden. Unlike Ident and the validity period, it can be hidden because a CI need not have a
criticality. Without a layout, the form shows it after the validity period as before, and the
detail page now also lists it in the *General* panel, after *Active*.
