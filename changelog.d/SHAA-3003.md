### Changed: the workflow designer shows its check results in the interface language

The problems the workflow designer lists under **Check**, in the state and transition inspectors and in the
publish dialog are now worded by the web interface from each problem's code, in English or German, instead of
showing the API's English text. This covers the draft check, a save or publish the server refuses, and the
approver warnings on the **Approvers** tab. A problem the interface does not know yet (from a newer server)
still shows the server's message.

API: each entry of `problems` in the draft check (`POST /api/v1/admin/workflow-definitions/{id}/draft/validate`)
and in the approver assignments (`GET`/`PUT …/approvers`) has a new optional `params` object with the data its
`message` names (state, transition and step keys, the field key, the type key, the value, counts). The field is
left out when a problem has none. No field was renamed or removed, and `message` is unchanged.
