### Changed: Administration › Dropdowns in the new look

The Dropdowns page now has the same header as the inventory. The breadcrumb, the title with the list
count, New list and the introduction sit on one band above the lookup lists. List names, parent lists and
the values of the selected list are shown in a monospaced font in the link colour, and Active and Archived
are pills with a dot. The list and value tables use the same headers as the other lists.

No behaviour, URL or permission changes.
