### Fixed: the header and sidebar fit narrow browser windows

Below about 900 px the header squeezed the search field to a few pixels, pushed **+ New CI** out of
view and wrapped the user name, and the sidebar forced a horizontal scroll bar below 820 px
([GH#182]). The search field now keeps at least 150 px. Below 960 px **New CI** shows as a **+**
button (screen readers still announce "New CI"), and the user's name opens a menu holding
**My account**, the theme and **Sign out**; the Administrator badge is not shown there. Below 820 px
the sidebar opens from a menu button next to the logo and closes on Escape or after choosing an
entry. Wider windows are unchanged. No API or database change.

[GH#182]: https://github.com/Shadoukita/ShadouCMDB/issues/182
