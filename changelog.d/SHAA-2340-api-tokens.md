### Changed: Administration › API tokens in the new look

The API tokens list now has the same header as the inventory. The breadcrumb, the title with the
token count, **New API token**, the introduction, the search and the filters sit on one band above
the table. Owners are shown in a monospaced font in the link colour, the status is a pill with a
dot (**Active**, **Expired**, **Revoked**), and the page numbers sit in the footer of the table.

After a token is created, the dialog that shows its secret keeps the same title band as the form
before it, and the owner is shown in the monospaced font.

No behaviour, URL or permission changes.
