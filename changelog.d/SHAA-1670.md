### Changed: a refreshed colour palette and type scale for the web UI

The web UI starts its move to a new design system. This first step changes colours, headings and
borders across every page at once, without moving anything:

- A cooler, higher-contrast grey palette. Secondary text is darker and easier to read.
- A clearer heading scale: page titles 20 px, card titles 16 px and section titles 14 px.
- Borders of text fields, selects and secondary buttons now have at least 3:1 contrast against the
  page (WCAG 2.1, 1.4.11), so empty fields are easy to spot.
- Field error messages in the dark theme are lighter, for AA contrast.

Custom brand colours (**Administration › Customization › Branding**) apply as before. Selected
rows, the active Administration menu entry and highlighted panels now use the primary colour; the
accent colour marks the current entry in the main sidebar only. A primary button keeps its label
contrast when hovered, in both themes.

**Upgrade:** nothing to do. If you set a custom primary colour, check the look of Branding's preview
once after the upgrade.
