### Security: the encryption master key is wiped from memory after use

The server and `shadoucmdb generate-encryption-key` kept a copy of the raw master key read from
`ENCRYPTION_KEY_FILE` (or generated) in freed memory after deriving the encryption subkeys from it
([GH#224]). It is now overwritten as soon as it is no longer needed, as the decrypted secrets
already were. This is defence in depth: reading it needed a memory dump of the process.

**Upgrade:** nothing to do.
