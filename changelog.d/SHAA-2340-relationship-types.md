### Changed: Administration › Relationship types in the new look

The relationship types list now has the same header as the inventory. The breadcrumb, the title with the
type count, New relationship type and the introduction sit on one band above the list. Type names and the
classes in a type's rules are shown in a monospaced font in the link colour, and Active and Archived are
pills with a dot. The type and rule tables use the same headers as the other lists.

No behaviour, URL or permission changes.
