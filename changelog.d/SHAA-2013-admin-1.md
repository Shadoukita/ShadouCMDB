### Changed: Administration navigation and the Users, Groups, Permission profiles, API tokens and Audit log lists

- **Navigation:** the Administration sections now appear in the sidebar, under **Administration**, instead of in a second column beside the page. Below 820 px they are in the navigation drawer, so Administration no longer scrolls sideways on a narrow window. While the sidebar is collapsed to icons, the sections appear beside the page as before. **Templates** is now named **Starter templates**, as on its page. Every Administration page shows its group in the breadcrumbs, for example *Administration / Access / Users*.
- **Lists:** Users, Groups, Permission profiles and API tokens use the same layout as the inventory. The table header stays in view while the rows scroll, each row has an actions menu, the arrow keys move between rows and Enter opens the selected one (for an API token, which has no page of its own, Enter opens its actions menu), and times show as relative time with the exact time in the tooltip. Each page has a short introduction and designed empty states with the next action.
- **Row actions:** a user's menu links to their API tokens and to their changes in the audit log. A profile's menu links to its users and holds **Clone**. **Revoke** for an API token has moved into the token's actions menu and still asks for confirmation. The confirmation after revoking appears as a notification.
- **Audit log:** shown as an event stream. Times are in UTC, each entry shows its source (UI, API, Import or System) and the event under a readable name, such as "Sign-in failed" instead of `login.failure`, coloured by its kind. The raw action is in the badge's tooltip. You can narrow the log by source with the chips in the toolbar; the selection is part of the address, so a filtered view can be bookmarked and shared.
