### Changed: Administration › Identity providers in the new look

The Identity providers list now has the same header as the inventory. The breadcrumb, the title with the
provider count, **New LDAP directory**, **New OpenID Connect provider**, the introduction and the note on
the sign-in order sit on one band above the table. Provider names are shown in a monospaced font in the
link colour, Enabled and Disabled are pills with a dot, and the table uses the same headers as the other
lists.

A provider's page has the same header as a CI page. It shows the breadcrumb, a key icon on a tile, the
provider name, chips for the status, the type and the number of accounts, and the issuer or directory URL
in a monospaced font with when it was last updated. The group mappings table uses the list tables'
headers.

No behaviour, URL or permission changes.
