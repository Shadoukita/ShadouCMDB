### Security: Requests with an excessive number of query parameters are refused early

An API request whose query string carries more distinct parameters than the endpoint documents,
plus a margin of 16, is now refused with `400 VALIDATION_ERROR` and the detail code
`too_many_keys`. Previously such a query was parsed to the end in quadratic time, so an
authenticated user could keep server worker threads busy for a significant time per request.
Requests with a few unknown parameters are still answered with `unrecognized_keys` listing them
by name, and repeating a documented parameter does not count against the limit.
