### Fixed: `shadoucmdb seed` shows the first-run hint on a fresh install again

On a freshly migrated database, `shadoucmdb seed` counted the built-in Business service class as
part of the data model and so never printed *"The data model is empty. Build it under
Administration, or install a starter template"*. The data model now counts as empty while no class
of your own exists, the same rule the web UI uses. In the printed counts, tables that contain
built-in rows show them separately, for example `ci_classes: 1 (built-in: 1)`. The total still
comes first, so a script that reads `<table>: <number>` keeps working if it ignores the rest of
the line.
