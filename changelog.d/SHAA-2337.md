### Changed: Inventory filters as chips, row selection and numbered pages

The inventory's title shows how many CIs match out of all CIs the user may view (for example
**36 of 1,245**) while a filter is applied. Every applied filter, including class, criticality,
validity and deleted CIs, is shown as a chip next to the search and is removed with its **×**.
Lookup value filters get one chip per list (for example *Status: In service, Maintenance*).
The class, criticality, validity and deleted selects moved from the toolbar into **Add filter**.
**Save view** next to the filters saves the current filters, sort and columns as a new view; the
view menu keeps its other actions.

A checkbox column selects rows, one by one or a whole page at a time. The footer shows how many
are selected; the selection is kept across pages and cleared when the filters change. **Bulk
edit** is shown but not available yet. The footer pages by number (‹ 1 2 3 … ›) instead of
First / Prev / Next / Last.

The CI name is shown in a monospaced font. When the list has no Class column, the class name is
shown under it. Criticality shows a bar meter next to its name. Lookup values with a colour (for
example a status) are shown as a pill; values without a colour stay plain text. The facet panel
sits beside the table without the count bars.
