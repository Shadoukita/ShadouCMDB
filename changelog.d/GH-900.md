### Fixed: the `MAIL_FROM` and `MAIL_REPLY_TO` examples in `.env.example` load when uncommented

`.env.example` showed `MAIL_FROM` and `MAIL_REPLY_TO` with a display name but without quotes around
the whole value. Uncommenting either line made the env file unreadable, so `migrate`, `seed` and
`serve` all failed to start with `Error parsing line` ([GH#900]). The examples now wrap the value in
single quotes, for example `MAIL_FROM='"ShadouCMDB" <cmdb-noreply@example.com>'`, and a comment
states that a value with a display name must be quoted this way.

**Upgrade:** if your env file has a `MAIL_FROM` or `MAIL_REPLY_TO` value with a display name that
is not wrapped in single quotes, wrap it as shown above.

[GH#900]: https://github.com/Shadoukita/ShadouCMDB/issues/900
