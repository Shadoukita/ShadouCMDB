### Changed: Administration › Export / import in the new look, in English and German

The configuration export and import page has the record head band of the other administration pages. The chosen
file and its state (Dry run, No changes, Imported, Not imported) show as chips under the title. The dry run, the
database changes and the list of changes are separate panels. Apply import and Cancel sit on the save bar docked
at the bottom of the page instead of below the last panel. Every text on the page follows the active language: the
explanations, the summary table, the section names, the change actions, the confirmation, the file errors, and
the statement counts and impact labels of the database changes. Messages that come from the API, such as
validation details and warnings, stay in English. At narrow widths the summary table scrolls inside its panel,
and long field changes wrap.

No URL, permission or API changes.
