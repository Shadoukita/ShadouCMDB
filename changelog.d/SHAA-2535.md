### Added: Export button on the inventory list

The inventory page header has an **Export** menu that downloads the current list as CSV, either
comma-separated or semicolon-separated (for Excel where the decimal separator is a comma). The file
holds every CI the list matches, not just the page shown: the same search, filters and sort, with
the visible columns in their order, including attribute columns when the list shows one class.
While a data-quality filter from the dashboard is applied, the export is unavailable, because the
export cannot apply that filter. When the user already runs two exports, or the server is busy with
other exports, the page says so and offers to try again; any other failure shows the API's message
and request id. Nothing to do on upgrade.
