### Added: CSV export of the inventory list

`GET /api/v1/configuration-items/export` returns the CIs the inventory list returns for the same
filters and sort, all of them (no page), as a CSV file with the columns given in `columns`
(built-in fields and `attributes.<key>`). The header row uses the column names a bulk import maps
by itself. The rows come from one consistent snapshot and are streamed, so large inventories do
not load into memory; a download cut short ends with a broken connection, never with a file that
looks complete. Only CIs of classes the caller may view are exported, and a reference to a CI the
caller may not view is left empty. Every field is quoted and values that a spreadsheet would run
as a formula are prefixed with `'`.

Each export is recorded in the audit log (action `export`, entity type `inventory`) with the
columns, sort, filters and row count, never the rows. A signed-in session must send the
`X-CSRF-Token` header as on a write. A user runs at most 2 exports at once (429 `RATE_LIMITED`)
and a server at most 4 (503 `SERVER_BUSY`). No schema change and nothing to do on upgrade.
