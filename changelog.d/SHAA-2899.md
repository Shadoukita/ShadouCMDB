### Fixed: Scrolling admin tables can be scrolled from the keyboard

The class permission matrix on a permission profile, the lists under **Users**, **Permission
profiles**, **Groups**, **API tokens**, **Audit log** and **Identity providers**, and a workflow's
grant matrix now take keyboard focus when they scroll inside their panel. Tab to the table and use
the arrow and Page keys to scroll it, also on a read-only profile where no checkbox can be focused.
Screen readers announce each table as a named region (WCAG 2.1.1).
