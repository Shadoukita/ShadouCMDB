### Security: source-map-js updated to 1.2.2 in the web UI build

The web UI build used `source-map-js` 1.2.1, which has a high-severity denial-of-service advisory
([GHSA-68fv-2mgg-jv7q]): a crafted indexed source map can block the event loop of the process that
reads it. The package is pulled in by the Vue compiler and PostCSS and runs only while the web UI
is built. It is not part of the shipped server binary or the container image, so running
installations were not exposed. The lockfile now pins 1.2.2, which fixes the advisory.

**Upgrade:** nothing to do.

[GHSA-68fv-2mgg-jv7q]: https://github.com/advisories/GHSA-68fv-2mgg-jv7q
