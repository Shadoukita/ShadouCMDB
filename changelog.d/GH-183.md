### Security: disabling, deleting or resetting a user revokes everything they could still use

Disabling or deleting a user now also revokes the API tokens they created for other owners, such as
service accounts ([GH#183]); before, those kept working until they expired (up to 366 days). A
password reset already did this. Disabling an account, and any password change or reset, also
drops a sign-in that was waiting for its second factor ([GH#191]); before, a second-factor step
started with the old password stayed valid for its five minutes. Each revoked token has its own
audit entry. No API or database change.

**Upgrade:** accounts disabled before the upgrade are not revisited: tokens they created for other
owners keep working. Review them under **Administration > API tokens** and revoke the ones you no
longer need. Before disabling an administrator, mint replacement tokens for the service accounts
they looked after.
