### Changed: Administration › Import in the new look

The import settings page now has the same header as a CI page, with the import status (turned on, turned
off, or disabled by the server) and "Administrator only" as chips. The switch and the server limits are
separate panels. Saving uses the save bar docked to the bottom of the page, as on the other administration
edit pages: it shows "Unsaved changes" once the switch is changed, offers Discard, and confirms the save
with a notification. The page is available in English and German.

No URL, permission or audit changes.
