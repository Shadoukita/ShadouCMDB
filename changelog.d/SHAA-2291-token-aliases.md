### Changed: Older style token names removed from the web interface

The stylesheets now use only the design token names: the older spacing steps (`--sp-1` to `--sp-6`),
`--radius`, `--shadow-pop`, `--fs-lg`, `--fs-xl`, `--c-text-muted`, `--c-ok`, `--c-danger-bg`,
`--c-danger-hover` and `--c-warn-bg` are gone, and `--c-warn-border` is now `--c-warning-border`.
`--c-danger` stays as the colour of danger dots, icons and marker bars. Every page looks exactly as
before.

No URL, permission or API behaviour changes.
