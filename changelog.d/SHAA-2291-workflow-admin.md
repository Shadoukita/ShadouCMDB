### Changed: Administration › Workflows and a workflow's Settings, Versions, Grants, Approvers and Notifications tabs in the new look, in English and German

The Workflows list now uses the inventory's head band: breadcrumb, title with the workflow count, intro and the
Search, CI type and Status filters, above the table card with status pills and numbered pages. A workflow's page
uses the record head band: its name with the Active or Inactive pill, the CI type, the current and draft
versions, its key and when it changed, an "Open instances" link to its running instances, and the tabs on the
band's lower edge. Settings, Grants, Approvers and Notifications are saved through the shared save bar at the
bottom of the page, which shows "Unsaved changes" with a Discard button, and a saved change is confirmed with a
toast. The Versions tab shows its statuses as pills; the migrate panel, the bootstrap ("Adopt existing CIs"), the
activation and delete confirmations and every message on these tabs follow the active language, so German users
no longer see English text there. The designer tab follows in a later step.

No URL, permission or API changes.
