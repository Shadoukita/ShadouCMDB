### Changed: Administration › CI classes in the new look

The CI classes list now has the same header as the inventory. The breadcrumb, the title with the class
count, New class, the introduction and the filters (show archived classes, area) sit on one band above
the class tree. Class names are shown in a monospaced font in the link colour, and Active and Archived are
pills with a dot.

The class page has the same header as a CI page: the class icon on a tile in the class colour, the name,
the area (a link to the classes of that area), Abstract and the state as chips, then the table name and
when the class was last updated. The attribute tables use the same headers and pills as the other lists.

No behaviour, URL or permission changes.
