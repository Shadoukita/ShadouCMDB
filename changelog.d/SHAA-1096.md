### Security: only an administrator can change requireMfa on the built-in Administrator profile

A user holding a clone of the Administrator profile, which spells out every permission but is not
the built-in profile, could set `requireMfa` on the built-in Administrator profile through
`PATCH /api/v1/admin/profiles/{id}`. Turning it off let every administrator sign in with a password
alone; turning it on ended the sessions of OIDC administrators whose provider does not prove MFA
([GH#405]). Changing the built-in profile now requires the built-in Administrator profile itself;
anyone else gets `403 FORBIDDEN`.

**Upgrade:** nothing to do. No API or schema change. If you hand out clones of the Administrator
profile, review the audit log for `permission_profiles` updates of the built-in profile by users
who are not administrators.

[GH#405]: https://github.com/Shadoukita/ShadouCMDB/issues/405
