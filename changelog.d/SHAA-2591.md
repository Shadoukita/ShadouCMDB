### Added: Notes tab on the CI detail page

The CI detail page has a **Notes** tab, with the number of notes on the tab. It lists the CI's notes
newest first, with the author and the time; hover over the time to see the exact date and time. The
text is shown exactly as it was typed, with its line breaks.

- Users with edit permission on the CI's class can add a note. A CI that has been deleted does not
  accept new notes.
- **Edit** and **Delete** appear only on notes you are allowed to change. That means your own notes
  while the edit window is still open. An administrator can delete any note at any time. If the
  server refuses a change, its message is shown on the note.
- If someone else saved the note while you were editing it, your text is kept. The saved text is
  shown next to it, and **Replace saved text** saves your version over it.
- Before a note is deleted, a confirmation shows the note's text.
