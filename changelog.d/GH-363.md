### Fixed: the header fits a 320 px wide screen

At 320 px (a phone, or a desktop browser zoomed to 400 %) the user's name in the header pushed every
page to about 400 px wide, so the page scrolled sideways ([GH#363], WCAG 1.4.10 reflow). Up to
480 px the header now shows the user's initials instead of the name; the name is still announced by
screen readers and shown as **Signed in as …** at the top of the opened user menu. On wider screens
the name is shortened with an ellipsis when space runs out, rather than widening the page.
No API or database change.

[GH#363]: https://github.com/Shadoukita/ShadouCMDB/issues/363
