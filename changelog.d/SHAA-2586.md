### Added: Bulk edit in the inventory

The inventory's **Bulk edit** action, on a selection of rows, now sets the same values on every
selected CI in one request. Add the fields to change (the criticality, and the attributes of the
class when the list is filtered to one class), enter the values (an empty value clears the field),
and apply. The result says how many CIs were updated and lists each refused CI with the reason the
server gave, for example a missing edit permission on its class or a value its class does not
accept. The refused CIs stay selected to correct and apply again. **Save only if every selected CI
can be updated** saves nothing when any CI is refused. A selection of more than 500 CIs is refused
before anything is sent. No action on upgrade.
