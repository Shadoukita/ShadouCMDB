### Changed: Administration › Permission profiles in the new look

The Permission profiles list now has the same header as the inventory. The breadcrumb, the title
with the profile count, **New profile**, the introduction, the search and the sort order sit on
one band above the table. Profile names are shown in a monospaced font in the link colour, the
**Built-in** and **Two-factor required** badges are pills, and the page numbers sit in the footer
of the table.

A profile's page has the same header as a CI page. It shows the breadcrumb, a shield icon on a
tile, the profile name, the **Built-in** and **Two-factor required** chips, the number of users
(a link to them for administrators who manage users), and when the profile was created and last
updated. The permission matrix uses the list tables' sentence-case column headers and pill badges.
The actions are unchanged.

No behaviour, URL or permission changes.
