### Changed: regression tests for workflow type permissions and state fields

No change in behaviour. New tests cover three cases the workflow fixes of this release ([GH#667],
[GH#668]) did not yet test: a manager whose type rights do not reach every subtype can neither
create a workflow that includes subtypes nor switch subtypes on; the configuration import refuses a
transition that takes the workflow's state field; and the final approval of a request refuses a
staged value for a field that has since become another active workflow's state field.
