### Added: Notifications bell in the web UI

The header now has a bell next to **New CI** showing how many of your notifications are unread. It
asks the server for the count once a minute while the browser tab is visible; nothing is pushed and
no outbound connection is made. Opening it lists your newest notifications (approval requested,
approval decided, workflow update, import finished) with the CI, workflow and who acted, as they
were when it happened. Selecting one marks it read and opens the workflow instance or import it is
about; when that record has been removed since, or is no longer visible to you, the notification
says **No longer available** instead. Each notification can be marked read or unread and dismissed,
and **Mark all read** marks everything shown read without touching notifications that arrived
after the panel was loaded.
