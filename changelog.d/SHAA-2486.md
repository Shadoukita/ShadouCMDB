### Fixed: Inventory keyboard shortcuts work from a row's selection checkbox

With focus on a row's selection checkbox, **↑**/**↓** move to the previous or next row's checkbox
and **e** opens the row for editing, as they do from the row's link. Space still ticks the
checkbox, so a run of rows can be selected from the keyboard alone. The shortcuts still do nothing
while typing in a text field, a select or the search box.
