### Changed: Sign-in and account screens take their texts from the message catalog

The sign-in screen (password, authenticator code and recovery code steps, single sign-on messages),
first-run setup, **My account** (password and two-factor authentication) and the required
two-factor set-up screen now take every text from the application's message catalog, which has an
English and a German version. The interface stays in English: there is no language setting yet.
The wording is unchanged, except that replacing recovery codes when only one is left now reads
"the 1 you have now stops working".
