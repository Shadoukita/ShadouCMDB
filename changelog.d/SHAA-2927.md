### Added: Find the delegate for "Delegate my approvals" without the user directory

`GET /api/v1/me/approval-delegations/candidates?q=` returns the users you can delegate your
approvals to. It returns only active users other than you, with their id, username and display name.

- If you may look up users (`GET /api/v1/principals`: the edit permission on business services or
  `users.manage`), `q` searches display names and usernames and returns up to 20 users.
- If you may not, `q` must be the exact username (case-insensitive). The answer is that one user or
  an empty list, and `exactMatchOnly` is `true`. An empty list looks the same whether the account
  does not exist, is disabled or is your own, so the lookup does not list or reveal the user
  directory (GH#839). Each user may make 30 such lookups a minute. Past that the endpoint returns
  429 `RATE_LIMITED` with `Retry-After`.

The endpoint needs a signed-in session. API tokens cannot call it.
