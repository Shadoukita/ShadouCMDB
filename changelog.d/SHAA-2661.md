### Changed: Customization's Navigation, Dashboard, List views and History sections use the message catalog

Every label, column header, button, hint and screen-reader text in Administration › Customization ›
Navigation, Dashboard, List views and History now comes from the English and German message
catalogs, like the page head, Branding and Layouts already did. The English texts are unchanged,
except that the lookup filter hint keeps the list's name as written (*None ticked: any Status*).
