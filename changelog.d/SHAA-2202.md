### Fixed: The workflow designer no longer offers the state field as a transition field

In a workflow's **Designer**, the transition inspector's **Add a field…** list now shows the
workflow's own state field greyed out with the note *state field: set by the states*, instead of
offering it. Its states set that field, so the check always refused it as a transition field and
**Publish** stayed disabled until it was removed. The state field of another active workflow on the
same type is still offered; the check names that workflow if it is chosen.
