### Changed: Layouts use free placement only; Customization › Layouts opens the editor on a CI

Detail and form layouts have one placement: every section is a window you move, resize and stack
in the layout editor on a CI page. The **Grid** / **Free** switch is gone. Tabs saved on the
12-column grid are not lost: each section becomes a window where it was on the grid, both when the
settings are read and when they are saved. The API still accepts `"placement": "grid"` (and tabs
without a placement), for example from older configuration exports, and stores them as free tabs.

**Customization › Layouts** no longer has its own preview and designer. Pick a class and press
**Edit CI: <name>** to open the layout editor on that class's most recently updated CI (or choose
another one). A class without CIs links to the create form's layout editor. The layout editor no
longer has preview width presets or **Open in the designer**.
