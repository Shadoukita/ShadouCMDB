### Changed: Required two-factor set-up in the new look

The page that asks a user to set up two-factor authentication, when a permission profile they hold requires
it, now uses the sign-in card instead of a page header and panels on the grey page. The reason is the lead
text, the password, QR code, setup key and recovery codes stay in the card, and the foot shows who is signed
in with a "Set it up later? Sign out" link. When the authenticator is already set up in another browser, the
card asks the user to sign out and sign in again with a code.

No URL, permission, API or sign-in behaviour changes.
