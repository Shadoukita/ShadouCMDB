### Changed: Redesigned navigation sidebar, header and user menu

The web UI's frame has the new look. The navigation sidebar is 232 px wide, with an icon next to each page (Dashboard, All configuration items, Bulk import, Business services, Search, Audit log, Administration). Class links keep their icon and live count, which now uses a monospace font. On desktop, **Collapse sidebar** at the bottom of the sidebar shrinks it to a 56 px icon rail. Each icon names its page as a tooltip, and the class list is hidden until the sidebar is expanded again. Each browser remembers the choice. Below 820 px the sidebar is still a drawer behind the menu button.

Without a logo, the application name now has a square mark in the accent colour next to it.

The header search shows a search icon and the `/` shortcut hint. Its suggestions put the CI name first, with the class and the matching attribute below.

The theme setting, the Administrator badge and **Sign out** have moved out of the header into a menu behind the user's initials and name, on every screen width. The menu also has a new **Density** setting: *standard* (the default, with compact rows) or *comfortable* (taller rows and controls). Each browser remembers it, like the theme.

Breadcrumbs use `/` between levels.
