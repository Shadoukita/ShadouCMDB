### Fixed: Set identifying and expected fields under Data model

The attribute dialog under Data model had no setting for `isIdentifying` or `isExpected`, so on an
upgraded installation the only way to mark a serial number or asset tag as identifying was the API
or a configuration import (GH#763). The dialog now has two options next to Required:

- **Identifying**: "Identifies one CI (not copied when cloning)".
- **Expected**: "Counts towards record completeness (not enforced on save)".

The attribute list shows an "Identifying" badge on marked fields. No migration is needed.
