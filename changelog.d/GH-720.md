### Fixed: upgrade notes said migrations run when the server starts

Several upgrade notes (migrations 0029–0031, 0035, 0036, 0053, 0060, 0061, 0063 and 0064) said the
migration "runs on start". `serve` does not migrate: it warns and answers `503
SCHEMA_NOT_MIGRATED` until the schema is current. The notes now name the actual step, running
`shadoucmdb migrate` before starting the new release. ([GH#720])
