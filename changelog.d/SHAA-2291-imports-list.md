### Changed: Imports in the new look

The Imports page now has the same header as the inventory. The breadcrumb, the title with the number of
imports, New import, the introduction and, for administrators, the All users filter sit on one band above
the table. File names are shown in a monospaced font in the link colour, the status is a pill with an icon,
and the page numbers sit in the footer of the table. Stop and Delete moved into the row's action menu and
still ask for confirmation first. The page is available in English and German.

No behaviour, URL or permission changes.
